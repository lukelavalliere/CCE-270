## Project layout

Keep these project files at the top level:

- `AGENTS.md`: project instructions and file-placement rules.
- `spec.md`: the app's requirements and behavior.
- `prompts.md`: a log of requests, changes, and whether they worked.
- `index.html`: the single-file web app entry point; keep it at the top level for GitHub Pages.

Use the numbered folders for all other project files:

- `00_planning/`: planning notes and sketches.
- `01_data/`: data files.
- `02_validation/`: hand calculations and test cases.
- `03_output/`: screenshots and exported results.

Save every new file in the appropriate top-level location or numbered folder. Keep `index.html` at the top level.

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
